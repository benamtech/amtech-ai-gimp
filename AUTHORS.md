## Provenance

Derived from prior experimental work on the Hermes Agent `image-compose`
skill and the `cli-anything-gimp` harness (CLI-Anything methodology,
https://github.com/HKUDS/CLI-Anything). The effect library consolidates that
work into a single self-contained package with no dependency on any one agent
runtime.

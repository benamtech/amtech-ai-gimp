# Format recipes (not locks)

Pick what the request needs. Do not force a leftover canvas.

## Magazine cover

Masthead first. Then the primary cover line. Then secondary lines.
One hero still. Date near the masthead.
A 2–4 column grid and quiet margins keep edges honest.
Contrast beats decoration. If you cannot read it at arm's length, it fails.

Harness map: portrait canvas, hero layer + crop offsets, type on a full-canvas overlay.

## Photography

Rule of thirds is a guide, not a law.
Leading lines pull the eye. Frame-in-frame holds a subject.
Diagonals move. Horizontals rest.
Leave a quiet band for type. A busy sky eats words.

Harness map: crop with `offset_x` / `offset_y`. Draw a rect before type if the still is busy.

## Ticker / breaking-news meme

Urgency bar. BREAKING or LIVE. Lower-third ticker. Short claim.

This is a layout grammar. Push heat, crop, and type as far as the ask goes.

## User-pasted images

A local path or chat attachment is the source.
Credit it as user-supplied.
Commons is the fallback for a public still.
Do not rebuild a canned poster when the user said "use this photo".
